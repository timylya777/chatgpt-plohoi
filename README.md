# ChatGPT плохой — переходи на Claude

Одностраничный сайт-памфлет. Один файл `index.html`, без сборки.

## Публикация в интернет (GitHub Pages, бесплатно, 5 минут)

1. Создай репозиторий на github.com, например `chatgpt-plohoi`, Public.
2. Залей туда `index.html` (Add file → Upload files).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет на `https://ТВОЙ-НИК.github.io/chatgpt-plohoi/`

## Локальный просмотр

```
python3 -m http.server 8095 --directory .
```

- Расписание деградации по дням недели (Пн–Вс)
- 5 реальных случаев помешательств со ссылками (CBS News 05.2026, NYT 08.08.2025, дела Сёльберга и Рейна, массовый феномен)
